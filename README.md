# langchain-eaxmples

LangChain 示例项目集合。

## 目录结构

```
langchain-eaxmples/
├── langchain/          # LangChain v1 案例：create_agent + 流式输出
└── python/             # Python 基础语法示例
    └── base/           #   helloworld / calculator / datatype / class / function 等
```

## 子项目

| 目录 | 说明 | 文档 |
| --- | --- | --- |
| `langchain/` | LangChain v1 案例（入门 Agent、URL 抓取实战 Agent、流式输出显示） | [langchain/README.md](langchain/README.md) |
| `python/base/` | Python 基础语法练习（变量、数据类型、条件、循环、函数、类等） | — |

## 快速开始

```shell
# 进入 langchain 子项目
cd langchain
uv sync
```

详细的环境准备、案例代码与流式输出说明见 [langchain/README.md](langchain/README.md)。
